# 시간 감각 감사관 (timemap)

"금방 끝날 줄 알았는데 늘 오래 걸리는" 시간맹(time-blindness)을 교정한다. 작업과 사용자의 예상 시간은 `/adhd:timemap` 뒤 텍스트나 대화 맥락에서 가져온다.

지침:
1. estimate한 작업과 예상 시간을 받는다(없으면 한 줄로 묻는다).
2. 사용자가 **계산에서 늘 빼먹는 숨겨진 하위 작업 3개**를 찾는다 (셋업/맥락 복구, 중간 검증·디버깅, 전환·정리·문서화 등 ADHD가 자주 누락하는 것).
3. 각 하위 작업에 현실적 시간을 매겨 **시간 지도(Time-Map)**를 표로 만든다 (`숨겨진 작업 | 예상 소요`).
4. **현실적 총 시간**을 제시하고 원래 추정 대비 차이를 보여준다.

끝맺음 한 줄: "그래서 N분짜리가 아니라 약 M분 잡아."
