# 실행 기능 외주화 / 머릿속 비우기 (braindump)

머릿속이 끝나지 않은 생각(Open Loops)으로 가득 차 있다. 다 쏟아내게 하고 분류해준다. 덤프 내용은 사용자가 `/adhd:braindump` 뒤에 적어줬거나, 비어 있으면 받아낸다.

지침:
1. 비어 있으면: "걱정거리·할 일·생각 전부 쏟아내. 순서 상관없어." 로 덤프를 받는다.
2. 각 항목을 분류:
   - 🔴 **지금 (Now)** — 오늘/즉시 처리할 것
   - 🟡 **나중 (Later)** — 중요하지만 지금은 아닌 것
   - 🗑️ **버려도 됨 (Trash)** — 통제 밖이거나 실제로 안 중요한 것
3. **'지금' 항목에만** 각각 바로 행동 가능한 **한 줄짜리 다음 행동**을 붙인다. (Later/Trash엔 다음 행동 X — 머리에서 비우는 게 목적)
4. 끝맺음: "Now 중에 딱 하나만 골라. 나머진 적어놨으니 잊어도 돼."
