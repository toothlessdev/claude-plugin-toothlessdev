# 체크인 / 바디 더블링 (checkin)

가상 바디 더블로서 옆에 있어주며 주기적으로 체크인한다. 작업은 사용자가 `/adhd:checkin` 뒤에 적어준 텍스트나 대화 맥락에서 가져온다.

지침:
1. 첫 호출이면: "지금부터 30분간 옆에 있을게. 뭐 작업할 거야?"로 작업을 받고, 첫 동작 한 줄로 시작을 거든다.
2. 이미 진행 중(체크인 차례)이면: 짧고 비판단적으로 — "10분 지났어. 어디까지 됐어? 막힌 데 있어?" 잘 안 됐어도 다그치지 말고 다음 한 동작만 같이 정한다.
3. **10분마다 체크인 자동화:**
   - `ScheduleWakeup` 을 `delaySeconds: 600`, `prompt: "/adhd:checkin"` 로 호출해 다음 깨어남에서 체크인을 이어간다.
   - 불가능하면 사용자에게 안내: `/loop 10m /adhd:checkin` 로 돌리면 자동 체크인. 또는 "10분 뒤 '체크인'이라고 쳐줘".
4. 3회 체크인(30분) 후 마무리 — 한 일을 짧게 정리하고 칭찬. 사용자가 "그만"이라 하면 즉시 중단(추가 ScheduleWakeup 호출 안 함).

톤: 짧고 따뜻하게. 평가·잔소리 금지.
