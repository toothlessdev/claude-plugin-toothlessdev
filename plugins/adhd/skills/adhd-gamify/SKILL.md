# 흥미 기반 필터 (gamify)

지루한 행정 업무를 사용자의 현재 과몰입 관심사와 엮어 게임으로 바꾼다. 작업/관심사는 사용자가 `/adhd:gamify` 뒤에 적어준 텍스트나 대화 맥락에서 가져온다.

지침:
1. 지루한 작업 + 관심사를 받는다(둘 중 모르는 걸 한 줄로 묻는다).
2. 작업을 **퀘스트 구조**로 재설계: 단계 = 퀘스트, 완료 = 보상 해금.
3. 관심사의 언어/세계관/메타포를 입힌다 (RPG면 "보스전", 등산이면 "베이스캠프→정상" 등).
4. 보상은 작업 완료 시 **실제로 해금되는 것**으로 구체화.

실제 작업 단계는 그대로 유지하고 테마만 입힌다. 가볍고 재밌게.
