# adhd

ADHD 뇌의 실행 기능(executive function)을 외주화하는 Claude Code 플러그인. 작업을 못 시작하거나, 자극이 부족하거나, 자꾸 딴 데로 새거나, 머릿속이 복잡할 때 — 상황에 맞는 7개 모드가 도와줍니다.

## 설치

```
/plugin marketplace add toothlessdev/claude-plugin-toothlessdev
/plugin install adhd@claude-toothlessdev
```

## 사용법

### ① 자연어 (이름 기억 불필요)

평소 말투로 던지면 라우터 스킬이 알아서 맞는 모드를 고릅니다:

- "나 이거 시작을 못 하겠어" → 작업 마비 부수기
- "머리 복잡해, 생각이 너무 많아" → 머릿속 비우기
- "자꾸 딴 데로 새" → 체크인 (바디 더블링)
- "이거 금방 끝날 줄 알았는데..." → 시간 감각 감사관

### ② 서브커맨드 (특정 모드 직접 호출)

| 커맨드 | 모드 | 하는 일 |
|---|---|---|
| `/adhd` | 라우터 | 현재 상태를 보고 7개 모드 중 하나로 자동 안내 |
| `/adhd:paralysis` | 작업 마비 부수기 | 시작 못 하는 작업을 1분 미만 첫 단계 하나로 쪼갬 |
| `/adhd:dopamine` | 도파민 메뉴 | 5분 에피타이저 / 20분 메인 / 10분 사이드 구성 |
| `/adhd:checkin` | 체크인 (바디 더블링) | 옆에 있어주며 10분마다 진행상황 체크 |
| `/adhd:switch` | 컨텍스트 전환 | 작업 A→B 사이 3분 멘탈 입가심 루틴 |
| `/adhd:gamify` | 흥미 기반 필터 | 지루한 일을 과몰입 관심사와 엮어 퀘스트화 |
| `/adhd:timemap` | 시간 감각 감사관 | 늘 빼먹는 숨겨진 하위 작업 3개로 현실적 시간 지도 |
| `/adhd:braindump` | 머릿속 비우기 | Open Loops를 Now/Later/Trash로 분류 |

예시:
```
/adhd:paralysis 분기 보고서 작성
/adhd:checkin 리팩터링 작업
/adhd:braindump
```

## 체크인 자동화 (바디 더블링)

`/adhd:checkin`은 10분마다 진행상황을 묻는 게 핵심입니다. 자동 체크인을 원하면:

```
/loop 10m /adhd:checkin
```

이러면 Claude가 10분마다 자동으로 깨어나 "어디까지 됐어?"라고 체크합니다. 멈추려면 "그만"이라고 하면 됩니다.

## 설계 원칙

모든 모드는 다음 톤을 따릅니다:

- **짧게** — 긴 설명은 그 자체로 작업 마비를 일으킴
- **다음 행동 하나만** — 7단계 계획보다 "지금 이거 하나"
- **다그치지 않기** — "괜찮아, 다음 한 동작만 보자"
